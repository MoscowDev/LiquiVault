# drips-dev-planner

Use the assessment to define ten daily milestones per repository. Write PLAN.md and tasks.json with stable task IDs, repository, day, acceptance checks, dependencies, and test commands. Target 50–60 meaningful commits only where justified by scope, with 5–6 as a daily planning estimate. Record external dependencies and never pad, backdate, or split inseparable changes to reach a quota.
