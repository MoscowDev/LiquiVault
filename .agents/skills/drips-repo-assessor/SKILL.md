# drips-repo-assessor

Inventory each repository and record exact revisions and working-tree changes. Run documented checks where feasible. Distinguish unit tests, simulated browser tests, and real network evidence. Examine commit content and progression, standalone prerequisites, overlapping concepts, and contributor setup. Present five rubric findings with evidence and blockers. Treat the rubric as maintainer-defined unless official sources establish it. Attribute a rejection cause only when reviewer feedback supports it.
